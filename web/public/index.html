Emparejar la app Android

  1. Instala y abre VerificaPE en el teléfono del dueño de la billetera.
  2. Concede el acceso a notificaciones cuando el sistema lo pida.
  3. Menú lateral → Emparejar → Escanear código QR.
  4. Apunta la cámara al código de abajo. ¡Listo!

Después activa app por app cuáles quieres monitorear (en «Apps monitoreadas», todo está desactivado por defecto).

⚙️ Dominio propio (recomendado): si tienes un dominio fijo (ej. https://caja.tudominio.com apuntando a este servidor con un túnel de Cloudflare con nombre), ponlo aquí: el QR apuntará siempre a él y nunca más tendrás que re-escanear aunque reinicies el servidor. Si usas el túnel rápido (URL cambia), pega la nueva URL aquí o abre el panel desde esa dirección para que el QR la tome solo.

Si usas start.ps1 o el docker compose --profile tunnel, el túnel gratuito de Cloudflare se configura solo y el QR apunta a la URL pública https://…trycloudflare.com. También puedes poner a mano la IP local o tu propia URL.

Zona sensible

«Eliminar canal» borra del servidor el canal y TODOS sus mensajes cifrados. «Olvidar» solo borra las claves de este navegador.

API de acceso

Crea un token de API para que un bot u otro servicio consulte los pagos recibidos. Los mensajes se entregan ya descifrados (el transporte va cifrado por HTTPS), así que el consumidor solo necesita el token. Puedes pausarlo temporalmente o revocarlo en cualquier momento.

Aún no hay token de API para este canal.

🔒 Al crear el token, la clave del canal se guarda en el servidor ENVUELTA (cifrada) con el propio token: una fuga de la base de datos sola no revela nada, y el panel sigue siendo E2E. Si no confías ni así en el servidor, simplemente no actives la API.

Endpoints de la API v1

GET  /api/v1/ping                    → estado del servicio
GET  /api/v1/messages?since=&from=&to=&limit=
     → mensajes DESCIFRADOS (desde/hasta en ms epoch; límite máx. 1000)
GET  /api/v1/stats                    → total, último id, primeras/últimas fechas
Header de autenticación:  X-API-Token: 
Token en pausa → 403 · Token inválido o revocado → 401

Los filtros de fecha se aplican en el servidor; los de texto (palabra clave, nombre, monto, app) están listos en el cliente de Node.
